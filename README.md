# Eploratory Data Analysis Portfolio 📊

## Overview 🔎

This repository contains a collection of exploratory data analysis mini-projects created with Python, mathplotlib.

The main goal of this repository is to demonstrate my ability to:

- inspect and clean real-world datasets,
- identify missing values and data quality issues,
- calculate descriptive statistics,
- analyze distributions and relationships,
- create clear data visualizations,
- formulate conclusions based on data,
- communicate analytical findings in a structured way.
